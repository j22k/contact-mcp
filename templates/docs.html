How to use

This server is a small MCP (Model Context Protocol) server. It exposes tools an MCP-compatible client — an AI assistant, agent framework, or your own script — can call to store and remove contacts in a local SQLite database. The Contacts page is a human-readable view of the same data.

Connect a client

Point your MCP client at this server's streamable-HTTP endpoint:

{{mcp_endpoint}}

The client speaks the MCP streamable-HTTP transport. No authentication is required by default — this server is intentionally open to any client. Requests are capped per IP address (see Configuration below); exceeding the limit returns 429.

Tools

insert_contact tool

Collects and stores a contact's name, phone number, and optional email address.

ParameterTypeRequiredNotes
namestringyesTrimmed; rejected if empty.
phone_numberstringnoDefaults to empty.
emailstringnoLowercased; must be unique if provided.
 
{
  "name": "Ada Lovelace",
  "phone_number": "+1-555-0100",
  "email": "ada@example.com"
}

Returns a confirmation string with the new contact's ID, or an error message if the email is already taken.

delete_contact tool

Deletes a stored contact by its numeric ID.

ParameterTypeRequiredNotes
contact_idintegeryesThe contact's id, shown on the Contacts page.
 
{ "contact_id": 4 }

Returns a confirmation string, or a not-found message if no contact has that ID.

Using the dashboard

The Contacts page lists every stored record, newest first. Each row has a Delete button that removes the contact immediately (after a confirmation prompt) — the same operation as the delete_contact tool, triggered from the browser instead of an MCP client. Use Refresh to reload the list after inserting contacts through a client.

Configuration

Set these as environment variables when running the server or its container:

DATABASE_PATH./contacts.dbWhere the SQLite file lives.
MCP_DEBUGfalseEnables debug mode and verbose logging.
ALLOWED_HOSTS—Comma-separated Host header(s) to accept (an IP address or domain). Enables DNS-rebinding protection; required in the Docker setup.
